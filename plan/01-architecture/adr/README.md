# Architecture Decision Records

One file per decision, numbered sequentially: `0001-short-title.md`. Copy `plan/_templates/adr.md`.

An ADR is required for: a stack change, a new external dependency, a change to the tenancy or auth model, a new public API surface, or any one-way door.

Never edit a decided ADR's decision. Supersede it with a new one and link both ways.
